## 本版更新

这一版把上游 GymMane 2.0.0 整包合并进来，并把康复模块与上游新功能的重叠处做了收口。

**上游 2.0.0 带来的新东西**

- 月度回顾：一个月的训练 / 饮食 / 习惯汇总成一份可分享的报告
- 计时循环训练（circuit）：按时间走的循环课表
- 每组笔记与签到：组间随手记一行
- 按肌群调下次组数：练完某个肌群觉得多 / 少，直接调下次的组数
- 自动渐进 / 减载周 / 动作替代：规则化的加重与休整
- PDF / CSV 报告导出、笔记文件夹、通知铃声、性能模式（关毛玻璃与动效）
- 女性肌肉图、Health Connect 写入、训练语音教练
- 间歇性禁食计时（饮食模块，默认关闭，在「设置 → 饮食」里开）

**康途这边的改动**

- 训练结束页：原来分散在三张卡里的「整场感觉 / 按肌群调组数 / 不适备注 / 睡眠精力」合成一张「本次小结」，全部即点即存、可撤销
- 动作详情页：跟着《计划》走的动作，把上游的规则控件收进「进阶选项」默认折叠，一屏只有一个进阶来源
- 排期：一个例程只吃一套排期——开了「计划周期」就自动清掉旧的周计划残留，不再出现幽灵训练日
- 康复入口统一规格；「自测基线」改名「康复自评」，并明确「填不上的可留空」
- 康复手册条目写明范围：**当前收录 12 周腰痛康复**（其他部位走 AI 提示词流程）
- **康复提示词随界面语言走**：中文 / 繁体中文用中文，其余语言用英文；安全规则一字未改
- 品牌名按语言显示：中文出「康途」，其他语言出「Kangtu」

**需要留意**

- 本次**更换了应用包名**（见上方迁移说明）：老用户请先在旧版导出备份，装完新版再导入
- 非中文语言下，分享标题与导出文件名从「康途 …」变成「Kangtu …」（例如 Strava 导出 `Kangtu 2026-11-04.fit`）。中文用户不受影响；有按旧文件名做自动归档习惯的需要改一下匹配规则
- 固定桌面小组件与 8 个小组件的自动刷新修好了（此前包名写死在代码里，会静默失效）

**已知问题**

- 康复提示词只有中文 / 繁体中文 / 英文三种：其余语言回落英文（与界面语言不完全一致）
- 少数界面细节待真机确认：训练结束卡的滚动与撤销、设置页图标底座对比度
