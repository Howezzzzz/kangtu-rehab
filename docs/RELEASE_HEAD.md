> ⚠ **本次更新更换了应用包名**（`com.gymmane.app` → `com.kangtu.app`），会作为**新应用**安装。
>
> **老用户请先迁移数据**（Android 沙箱禁止跨应用读旧数据，无法自动迁移）：
> 1. 打开**旧版**康途 →「设置 → 备份」→ 导出 ZIP（含照片/视频）
> 2. 安装新版（桌面上会出现第二个图标，旧版仍在）
> 3. 新版里「导入备份」选那个 ZIP → 核对训练历史 / 康复档案 / 照片无误
> 4. 确认无误后再卸载旧版
>
> **需要重新授权/重新添加**：Health Connect 权限、通知权限、桌面小组件、精确闹钟。
>
> 换包名的原因：旧包名与上游 GymMane 相同但签名不同，装过上游的设备无法安装康途、两个应用也不能共存；换名后可共存，且显示名「康途」与包名一致。
>
